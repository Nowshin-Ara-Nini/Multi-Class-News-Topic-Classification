# Data Directory

Place your dataset files here:

- `Training_data_9.csv` — Training data (88,829 rows)
- `Test_data.csv` — Test data (12,000 rows)

## Expected Format

Both CSV files should have two columns:

| Column | Description |
|--------|-------------|
| `News Headline` | The news headline text |
| `News Topic` | One of: Business, Science and Technology, Sports, World News |
